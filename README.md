# COSMICO AUTO EDITOR — site institucional

## Arquivos
- `index.html`: apresentação pública do aplicativo.
- `privacy.html`: política de privacidade.
- `terms.html`: termos de uso.
- `style.css`: identidade visual responsiva.

## Publicar com GitHub Pages
1. Crie um repositório público no GitHub chamado `cosmico-auto-editor`.
2. Envie todos os quatro arquivos para a raiz do repositório.
3. Abra Settings → Pages.
4. Em Build and deployment, escolha Deploy from a branch.
5. Escolha a branch `main` e a pasta `/ (root)`, depois Save.
6. Aguarde o GitHub publicar o site.

Os endereços esperados serão:
- https://italosou7.github.io/cosmico-auto-editor/
- https://italosou7.github.io/cosmico-auto-editor/privacy.html
- https://italosou7.github.io/cosmico-auto-editor/terms.html

Confirme os endereços depois da publicação. Não informe ao Google URLs que ainda não estejam públicas.

## Revisão obrigatória antes do envio ao Google
Esta versão foi redigida a partir do código do COSMICO AUTO EDITOR disponibilizado para análise. Confirme especialmente:
- se o aplicativo usa somente armazenamento local para tokens e configurações;
- quais dados são enviados a serviços de IA em cada funcionalidade;
- se o uso do ChatGPT Web via navegador continua ativo;
- se o endereço de e-mail pode ficar público.

Atualize a política sempre que o aplicativo passar a armazenar dados em nuvem, coletar novos dados ou integrar novos provedores.
