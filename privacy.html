Política de Privacidade

Última atualização: 21 de novembro de 2026

Esta Política explica como o COSMICO AUTO EDITOR, aplicativo para Windows operado individualmente por seu desenvolvedor, trata informações durante seu uso. O aplicativo é uma ferramenta de uso interno para preparar e administrar conteúdo audiovisual.

1. Informações tratadas

  • Dados de autenticação do YouTube: quando o operador conecta um canal, o Google OAuth fornece credenciais de autorização (tokens) para executar as ações aprovadas pelo titular.
  • Dados do canal: informações básicas disponibilizadas pela YouTube Data API, como identificador, nome e identificador público do canal, para confirmar qual canal foi autorizado.
  • Arquivos de mídia e produção: vídeos, áudio, imagens, miniaturas e transcrições selecionados pelo operador para edição e publicação.
  • Configurações locais: preferências, caminhos de arquivos, configurações do programa e registros técnicos necessários ao funcionamento.
  • Chaves de serviços externos: chaves de API fornecidas pelo próprio operador, quando ele ativa integrações opcionais.

2. Como as informações são utilizadas

As informações são utilizadas para autenticar os canais escolhidos, consultar informações básicas desses canais, preparar vídeos e metadados, enviar vídeos e miniaturas quando solicitado pelo operador, e diagnosticar falhas do aplicativo.

3. YouTube Data API e Google

O aplicativo usa OAuth 2.0 e a YouTube Data API. A permissão solicitada no código atual é https://www.googleapis.com/auth/youtube.force-ssl, que permite as operações do YouTube autorizadas pelo titular, incluindo gerenciamento e publicação de conteúdo. O aplicativo não solicita a senha da conta Google: a autorização ocorre na página oficial do Google.

O uso e a transferência de informações recebidas das APIs do Google para qualquer outro aplicativo obedecem à Política de Dados do Usuário dos Serviços de API do Google, incluindo os requisitos de Uso Limitado. O titular pode revogar o acesso do aplicativo nas configurações de segurança da Conta Google.

4. Serviços externos de inteligência artificial

Quando os recursos correspondentes são utilizados, o aplicativo pode enviar prompts, trechos de transcrição, imagens de referência ou outros materiais selecionados para serviços externos, incluindo a API do Google Gemini. O fluxo também pode utilizar sessões de navegador autenticadas pelo próprio operador para ferramentas de IA na web. Esses serviços recebem os dados necessários à solicitação e os tratam conforme seus próprios termos e políticas. O operador deve consultar as políticas desses provedores antes de enviar conteúdo.

5. Armazenamento e segurança

Os tokens OAuth e as configurações são gravados em arquivos locais no computador em que o aplicativo é executado. Os arquivos de vídeo, áudio, imagens e resultados de edição também permanecem nos locais escolhidos pelo operador. O aplicativo não mantém, por padrão, um servidor próprio ou banco de dados central para armazenar esses materiais. O operador é responsável por proteger o computador, restringir o acesso aos arquivos e manter cópias de segurança seguras.

6. Compartilhamento

O aplicativo não vende dados pessoais. Informações são transmitidas aos provedores externos necessários para executar uma função solicitada pelo operador, como Google/YouTube e serviços de IA habilitados. O conteúdo também é enviado ao YouTube quando o operador aciona uma publicação.

7. Retenção e exclusão

Os arquivos locais permanecem no computador até que o operador os exclua. Para interromper a autorização do YouTube, o titular pode revogar o acesso na Conta Google e apagar os arquivos de token locais do aplicativo. A exclusão local não apaga vídeos já publicados no YouTube nem dados que provedores externos precisem manter conforme suas políticas e obrigações legais.

8. Crianças e público

O aplicativo é uma ferramenta de produção operada por um adulto e não é destinado a coletar diretamente informações pessoais de crianças.

9. Alterações nesta política

Esta política poderá ser atualizada quando as funcionalidades, integrações ou práticas de tratamento de dados mudarem. A data no início da página indicará a revisão mais recente.
